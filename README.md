# Портфолио сайт — Netlify гарын авлага

```
index.html                    нүүр хуудас
album.html                    төслийн хуудас
admin.html                    админ хэсэг
data.js                       бүх мэдээлэл (админ автоматаар бичдэг)
style.css                     загвар
netlify.toml                  Netlify тохиргоо
netlify/functions/github.mjs  GitHub прокси — токен энд байна
photos/                       зурагнууд (админ автоматаар үүсгэдэг)
```

## 1. Байршуулах

1. Бүх файлыг GitHub repo-д байрлуул.
2. Netlify → Add new site → Import from GitHub → тэр repo-г сонго.
3. Build command хоосон, Publish directory `.` (netlify.toml дотор бичээстэй).
4. Deploy дарна.

## 2. Environment variables (нэг удаа)

Netlify → Site configuration → Environment variables:

| Нэр | Утга |
|---|---|
| `GITHUB_TOKEN` | fine-grained PAT, энэ repo-д `Contents: Read and write` |
| `GITHUB_OWNER` | GitHub хэрэглэгчийн нэр |
| `GITHUB_REPO` | repo нэр |
| `GITHUB_BRANCH` | `main` (заавал биш) |
| `ADMIN_PASSWORD` | админд нэвтрэх нууц үг — урт, таамаглахад хэцүү байг |

Хадгалсны дараа **дахин deploy** хийнэ (Deploys → Trigger deploy). Env
variable шинээр нэмэхэд заавал дахин deploy шаардлагатай.

> Токен зөвхөн серверийн талд байна. `admin.html` хуудсанд болон хөтөч рүү
> хэзээ ч илгээгддэггүй. Токеноо хэн нэгэнд, чатад ч илгээж болохгүй.

## 3. Админ ашиглах

`https://<таны сайт>/admin.html` руу орж нууц үгээ бичнэ. «Сануулах» сонголтыг
идэвхжүүлбэл нууц үг тухайн хөтөч дээр үлдэх тул дараагийн удаа шууд нэвтэрнэ.
Хамтын компьютер дээр сануулахгүй байхыг зөвлөе. Устгах бол хөтөчийн сайтын
өгөгдлийг цэвэрлэнэ.

Дараах бүхнийг админаас солино:

- **Холбоо барих** — нэр, байршил, и-мэйл, утас, Instagram нэр, Instagram
  холбоос, товчны бичиг, танилцуулга мөр.
- **Төслүүд** — нэмэх, устгах, дараалал солих, нэр/он/газар/**тайлбар**,
  нүүр зураг.
- **Зурагнууд** — олноор нэмэх, тус бүрд тайлбар бичих, дараалал солих, хасах.

Доод талын **GitHub рүү хадгалах** товч дарахад зургууд `photos/<slug>/` руу
хуулагдаж, `data.js` шинэчлэгдэнэ. Netlify өөрөө дахин deploy хийж, 1–2 минутын
дараа сайт дээр гарна.

## 4. Зургийн хэмжээ

- 2 МБ-аас **бага** зургийг эх чанараар нь хэвээр хадгална.
- 2 МБ-аас **их** бол хөтөч дээр автоматаар шахаж, 2 МБ-д багтах хүртэл
  чанар болон хэмжээг аажим бууруулна (эхлээд 2400px / чанар 0.85).
- Нүүр зургийг үргэлж 1600px болгож жижигрүүлнэ.

## 5. Зураг хамгаалалт — бодит байдал

Баруун товч, чирэх, утасны удаан дарах гурвыг хаасан. Энгийн хэрэглэгч зураг
хадгалж чадахгүй. Гэхдээ **бүрэн хамгаалалт биш**: хөтөч зургийг харуулахын
тулд заавал татдаг тул DevTools эсвэл дэлгэцийн зураг авалтаар авах боломжтой.
Үнэхээр хамгаалах шаардлагатай бол:

- усан тэмдэг (watermark) нэмэх,
- сайт дээрх зургийг зориуд бага нягтралтай тавих (жишээ нь 1200px),
- эх файлыг зөвхөн захиалагчид тусад нь өгөх.

Хүсвэл админ дээр «усан тэмдэг автоматаар нэмэх» сонголт хийж өгч болно.

## 6. Санамж

- Төслийг устгахад зургийн файл repo дээр үлддэг. Хэрэгтэй бол GitHub дээрээс
  гараар устгана.
- `data.js`-ийг гараар засаж болно, гэхдээ дараагийн хадгалалтаар дарагдана.
- Хадгалаагүй зураг байхад хуудас хаах гэвэл хөтөч сануулна.
